📂 Cargar datos del seguimiento

    
Para restaurar tus tareas, contrapartes y configuraciones guardadas, selecciona el archivo de datos.

    

      Estructura de carpeta:

      📁 Seguimiento_tareas/

        ├── seguimiento.html ← este archivo

        └── datos/

          ├── datos_T3.json ← tareas y configuración

          └── imagenes/ ← imágenes adjuntas


      Al copiar la carpeta completa a otro computador, solo necesitas abrir este HTML y cargar el archivo JSON correspondiente al trimestre.
